## What it does

<CardGrid>
	<Card title="Output format" icon="open-book">
		Grid moments of each species, fields, marker samples and the run's provenance in one `xarray.Dataset` layout, the same for every code.
	</Card>
	<Card title="Validator" icon="approve-check">
		`validate` lists every problem of a dataset (names, dims, units, frame, provenance); files are checked when written and when read.
	</Card>
	<Card title="Field maps" icon="setting">
		Magnet maps, coil fields and fields computed offline as netCDF grids, interpolated multilinearly to any position, with a choice of what holds outside the grid.
	</Card>
	<Card title="Light" icon="rocket">
		Needs NumPy, SciPy and xarray only, so a code that writes or reads the layouts does not depend on the codes that produce them.
	</Card>
</CardGrid>
